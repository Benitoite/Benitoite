01

Signal architecture

The frame never leaves the GPU.

Capture, interpret, collapse, draw. The pipeline turns a camera texture into a single geometric path without a CPU image round-trip.

  1. A / 01

    Acquire

    AVCaptureVideoDataOutput supplies BGRA pixel buffers from the active camera.

    INPUT / BGRA
  2. A / 02

    Expose

    CVMetalTextureCache presents each buffer as a zero-copy Metal texture.

    TRANSFER / 0×
  3. A / 03

    Adapt

    An order-9 compute traversal stops early in light cells and dives deeper in dark cells.

    DEPTH / 2–9
  4. A / 04

    Render

    Repeated points collapse on-GPU; square-capped quads draw the remaining continuous path.

    OUTPUT / 1 LINE

02

Dual render profiles

Same path.
Opposite signal.

Both modes use identical aspect-fill camera framing and stroke geometry. Density and tone decide what the line reveals.

MODE / 01 MASTER POSITIVE

Black path / white field

Bright areas hold a coarse line. Dark regions resolve into progressively denser turns.

MODE / 02 MASTER REVERSE

White path / black field

Bright regions receive the dense curve while darkness keeps a broad, spare white line.

↻

Upright by design. AVFoundation’s rotation coordinator keeps both feeds correctly oriented as the device moves.

04

Source history / annotated

A five-year question becomes a camera.

The routine grew through an open-image community exchange: a request for a structured, single-line fill; a browser experiment; public code; then a native real-time interpretation.

08 MAY 2021 Q / 001

The inquiry

Lyle Kroll asks the G’MIC community about a variable-density Hilbert preset: a single line fill related to traveling-salesman renderings, but with a more structured path and, ideally, other fill formulas.

26 JUL 2026 P / 002

The working browser tool

Kroll returns with Tin Tran’s Adaptive Continuous Hilbert Image Maker, produced through conversational coding and demonstrated with a 4000 × 4000 single-line result.

27–28 JUL 2026 S / 003

Code, license, extensions

When HIRAM asks for the repository and FOSS status, Tran publishes the ChatGPT-generated routine “as is.” An MIT license was applied to the code by its author in the conversation.

JUL 2026 HC / 009

The native instrument

Richard E Barber translates the adaptive idea into live iOS camera processing: Metal compute, zero-copy textures, continuous output, stills, and synchronized movies.

DISCUSSION ABSTRACT REV. A

What the group was really after

Not simply a standard Hilbert curve, but a structured path whose local density follows image tone while the fill remains one unbroken line.

  • Kroll distinguishes the idea from existing traveling-salesman / Voronoi line fills.
  • He floats Peano and other space-filling families as possible future choices.
  • Doug-Phoenix points to G’MIC’s newer shape_hilbert command as adjacent groundwork.
  • G’MIC’s David Tschumperlé says the adaptive concept is feasible there, with implementation time needed.
